# Documentation history

[Download the original documents](./documents.tar.gz) · [File list and SHA-256 checksums](./INDEX.json)

This archive preserves the exact documents consolidated on September 9, 2026: the RFC and its completion audit, implementation plans, earlier investigations, scenario specifications and detailed provenance notes. It also retains the former module/stack notes. Every archived file was checked against its original bytes before removal or rewriting.

These are historical records. Current guidance is in [methods](../methodology.md), [benchmark definitions](../benchmarks.md) and [running/publishing](../reporting.md). Current performance evidence remains in the generated report packages.

Extract into a separate directory to inspect the original paths:

```sh
mkdir documentation-history
tar -xzf docs/history/documents.tar.gz -C documentation-history
```

Links inside archived documents retain their original repository-relative paths. Older artifacts may name these original documentation paths; the archive's file index locates them.
